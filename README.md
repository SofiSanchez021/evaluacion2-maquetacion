# Ruta Patrimonio — Catálogo Web (Tema 16)

Catálogo web dinámico para **Ruta Patrimonio** (*"Historia viva del Eje Cafetero"*), desarrollado con Bootstrap 5.3, variables CSS personalizadas y JavaScript vanilla.

## Funcionalidades

- Filtro por categoría (`Museo`, `Parque`, `Monumento`, `Cultural` y `Todas`).
- Búsqueda en tiempo real por nombre o descripción.
- Ordenamiento por nombre (A - Z) y por valor de entrada (`precioEntrada`) de menor a mayor o de mayor a menor.
- Contador accesible (`aria-live="polite"`) y diseño adaptable a celular (1 columna), tableta (2 columnas) y escritorio (3 columnas).

## Cómo verlo

- **Sitio publicado (GitHub Pages):** https://sofisanchez021.github.io/evaluacion2-maquetacion/
- **En local:** abre `index.html` en tu navegador o con Live Server en VS Code.
